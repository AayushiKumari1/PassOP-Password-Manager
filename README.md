# PassOP – React Password Manager

**PassOP** is a modern and secure **Password Manager** built with **React.js** and **TailwindCSS**. It enables users to **securely store, manage, edit, copy, and delete passwords** for different websites through a clean, responsive, and intuitive interface. Passwords are **encrypted using AES encryption before storage**, ensuring that sensitive credentials remain protected. The application integrates with a local **REST API backend** and provides real-time **toast notifications** for every user action.

---

##  Features

-  **Secure Password Storage** – Passwords are encrypted using **AES Encryption** before being stored, ensuring sensitive credentials remain protected.
-  **Add & Save Passwords** – Store website credentials with a single click.
-  **Edit & Delete Entries** – Easily update or remove saved credentials.
-  **Show/Hide Password** – Toggle password visibility securely.
-  **Copy to Clipboard** – Instantly copy website URLs, usernames, or passwords.
-  **Real-time Notifications** – Beautiful alerts powered by **React Toastify**.
-  **Responsive Design** – Clean and intuitive UI built with **TailwindCSS**.
-  **REST API Integration** – Seamlessly communicates with a backend running at `http://localhost:3000/`.

---
##  Tech Stack

**Frontend:** React.js, TailwindCSS
**Libraries:** React Toastify, UUID
**Backend:** RESTful API (Node.js/Express.js)
**Security:** AES Encryption
**Icons:** Lordicon Animated Icons
